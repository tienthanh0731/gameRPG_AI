Thank you for purchasing my Survival pack! This brief guide will help you understand how to set up rigging and textures correctly.


***** RIGGING *****
For the .fbx and .glb formats the characters and animals are supplied with a ready-made rig, here are some points to correctly configure these

- In Unity, for characters you can use the "Humanoid" rig setting in the Inspector under the "Rig" tab for characters

- Configure the rig/avatar settings as shown in the provided screenshots: "Character Rig Body Setup" and "Character Rig Head Setup"

- For other game engines, refer to the bone structure described in the provided screenshots: "Character Bones" and "Animal Bones"


***** TEXTURES *****
Textures may appear blurry if applied directly due to their small size. You need to change some settings once imported into the game engine

- In Unity, select the textures you want to use and modify the settings in the inspector as shown in the provided "Texture Setup" file

- For other game engines, change these settings:
	- Mipmaps: OFF
	- Filters: NONE
	- Compression: NONE
	- Interpolation: Closest (it is usually set to linear)
	- Disable any setting that blurs the image

- To modify colors on textures and work with small files, I recommend using LibreSprite
